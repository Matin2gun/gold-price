# سامانه لحظه‌ای و هوشمند نرخ واقعی شمش طلا ۲۴ عیار ایران
### Real-time 24K Gold Bullion Terminal (Iran) — 30s Auto Update

یک سامانه جامع و بی‌درنگ (Real-time) برای محاسبه ارزش ذاتی، ریاضی و جهانی **شمش طلا ۲۴ عیار (با خلوص ۹۹۹.۹)** در بازار ایران، مقایسه با مظنه‌های بازار داخلی، و سنجش حباب قیمتی با قابلیت به‌روزرسانی خودکار هر **۳۰ ثانیه یک‌بار** و اتصال مستقیم به دامنه اینترنتی.

---

## ویژگی‌های کلیدی
- **واکشی زنده قیمت انس جهانی از TradingView:** استخراج نرخ لحظه‌ای XAU/USD (طلا) و XAG/USD (نقره) از طریق TradingView Scanner API و فال‌بک یاهو فایننس.
- **واکشی زنده نرخ‌های داخلی از TGJU:** دریافت نرخ لحظه‌ای دلار آزاد، طلای ۱۸ عیار، طلای ۲۴ عیار، نقره ۹۹۹ و مثقال طلا (مظنه آبشده).
- **موتور تحلیلی و فرمول ریاضی ارزش ذاتی شمش ۲۴:**
  $$\text{ارزش ذاتی هر گرم شمش ۲۴ عیار} = \frac{\text{نرخ انس طلا (دلار)} \times \text{نرخ دلار آزاد (تومان)}}{۳۱.۱۰۳۴۷۶۸}$$
- **سنجش خودکار حباب شمش و اوزان مختلف:**
  $$\text{حباب (تومان)} = \text{قیمت بازار} - \text{ارزش ذاتی}$$
  $$\text{درصد حباب} = \left(\frac{\text{حباب}}{\text{ارزش ذاتی}}\right) \times ۱۰۰$$
- **ماتریس اوزان استاندارد شمش:** محاسبه ارزش واقعی، نرخ بازار و حباب برای شمش‌های ۱ گرم، ۲.۵ گرم، ۵ گرم، ۱۰ گرم، ۲۰ گرم، ۱ انسی (۳۱.۱ گرم)، ۵۰ گرم، ۱۰۰ گرم، ۲۵۰ گرم، ۵۰۰ گرم و ۱ کیلوگرم (استاندارد بانکی).
- **به‌روزرسانی خودکار هر ۳۰ ثانیه:** با انیمیشن شمارش معکوس دایره‌ای و وب‌سوکت (WebSocket) دوطرفه به همراه فال‌بک خودکار REST API.
- **داشبورد مالی مدرن و اختصاصی:** طراحی تاریک (Dark Mode) استاندارد پایانه‌های بورس طلا، سازگار با موبایل و دسکتاپ، تغییر واحد بین تومان و ریال، نمودار تحلیلی Chart.js، ماشین‌حساب هوشمند و ثبت لاگ زنده تیک‌ها.
- **آماده استقرار روی دامنه اینترنتی شخصی:** به همراه Dockerfile، docker-compose و کانفیگ Nginx و SSL.

## راه‌اندازی سریع محلی (Local Run)

### روش ۱: در ویندوز
کافیست فایل `start.bat` را اجرا کنید، یا در خط فرمان:
```bash
pip install -r requirements.txt
python app.py
```

### روش ۲: در لینوکس / مک
```bash
chmod +x start.sh
./start.sh
```

سپس در مرورگر خود آدرس زیر را باز کنید:
```
http://localhost:8000
```

## مسیرهای API (REST Endpoints)

| مسیر | متد | توضیحات |
| :--- | :---: | :--- |
| `/api/rates` | `GET` | دریافت آخرین نرخ‌های محاسباتی، حباب و منابع |
| `/api/history` | `GET` | تاریخچه نقاط قیمتی ثبت‌شده برای نمودار |
| `/api/refresh` | `POST` | ارسال سیگنال به‌روزرسانی فوری بدون انتظار تایمر ۳۰ ثانیه |
| `/api/calculate` | `POST` | محاسبه ارزش شمش بر مبنای وزن دلخواه یا بودجه سرمایه‌گذار |
| `/api/health` | `GET` | وضعیت سلامت سرور و فعال بودن حلقه ۳۰ ثانیه‌ای |
| `/ws` | `WebSocket` | استریم داده‌های زنده در هر تیک ۳۰ ثانیه |
