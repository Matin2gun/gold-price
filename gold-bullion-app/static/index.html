راهنمای اتصال اپلیکیشن به دامنه شخصی

این برنامه با بک‌اند پایتون FastAPI و موتور واکشی مستقل ۳۰ ثانیه‌ای طراحی شده است و آماده اتصال مستقیم به هر دامین اینترنتی (مثل gold.yourdomain.com) است:

روش ۱: استقرار با Docker روی سرور مجازی (VPS)

docker build -t gold-bullion-app .
docker run -d -p 8000:8000 --name gold-app --restart always gold-bullion-app

روش ۲: اتصال دامین از طریق Nginx و SSL رایگان (Certbot)

server {
  server_name gold.yourdomain.com;
  location / {
    proxy_pass http://localhost:8000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
  }
}

روش ۳: استقرار ابری در پلتفرم‌های Render / Railway

کافیست پروژه را به مخزن GitHub خود متصل کنید و در پلتفرم Render یا Railway گزینه New Web Service را انتخاب کنید. در پنل پلتفرم، در بخش Custom Domains دامنه خود را اضافه کنید.
